## 📌 Project Overview
This project provides key insights into bank loan applications, total funded amount, received payments, average interest rates, and Debt-to-Income (DTI) ratios to monitor financial health and risk management.

### Key Features:
- **Executive Summary:** Overview of total loan applications, funded amounts, and total received amounts.
- **Good Loan vs. Bad Loan KPI Metrics:** Distinction between fully paid loans and defaulted loans.
- **Interactive Visual Analytics:** Monthly trends, regional analysis, loan term distribution, and purpose breakdown.
